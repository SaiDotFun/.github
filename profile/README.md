Sai is a perpetual futures exchange on Nibiru. This organization brings
together the Sai product, developer tools, and the infrastructure behind them.

### Start Here

| Project | What You'll Find |
| --- | --- |
| [Open Sai](https://github.com/SaiDotFun/open-sai) | Public tooling and selected development work for Sai, including the `sai` trader CLI. |
| [Nibiru](https://github.com/NibiruChain/nibiru) | The L1 codebase behind Sai, with EVM and Wasm smart contract support. |

### Build with Sai

Start with the [developer documentation](https://sai.fun/docs/) for Sai's
interfaces and integration guides. Explore the
[`sai` CLI](https://github.com/SaiDotFun/open-sai/tree/ud/sai-cli/cli) for
terminal-based trading and account tools.

We publish tools and selected development work here. Each repository explains
its own scope, license, and contribution process.
